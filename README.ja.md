# Cisco Config Extension

Zed用のCiscoデバイス設定ファイルのシンタックスハイライト拡張機能

**English version: [README.md](README.md)**

## Features

- シンタックスハイライト
- 設定アウトライン（実験的）


## 対応プラットフォーム

設定ファイルで一般的に使用される構文がサポートされています。
- IOS
- IOS-XE
- NX-OS

以下のプラットフォームは、IOSと重複する構文に対して類似のシンタックスハイライトを提供します。
- IOS-XR
- ASA
