# Cisco Config Extension

Syntax Highlighting for Cisco Device Configuration in Zed

**日本語版: [README.ja.md](README.ja.md)**

## Features

- Syntax highlighting (In development)
- Configuration outline (Experimental)


## Supported Platforms

Syntaxes commonly used in configuration files are supported.
- IOS
- IOS-XE
- NX-OS

The following platforms provide similar syntax highlighting for constructs that overlap with IOS:
- IOS-XR
- ASA
